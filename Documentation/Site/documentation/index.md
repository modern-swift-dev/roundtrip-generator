# Documentation

## API generation tutorial

[Describe an API and generate clients and servers](/docs/roundtrip-generator/documentation/api-generation/). The tutorial covers seven output formats, runtime dependencies, output policies, and migration notes.

## API references

- [SwiftApiGenerator](/docs/roundtrip-generator/api/swiftapigenerator/documentation/swiftapigenerator/) — Swift clients using RoundTrip and RoundTripREST.
- [SwiftVaporGenerator](/docs/roundtrip-generator/api/swiftvaporgenerator/documentation/swiftvaporgenerator/) — Vapor server projects and generated server files.
- [KotlinApiGenerator](/docs/roundtrip-generator/api/kotlinapigenerator/documentation/kotlinapigenerator/) — Kotlin Multiplatform clients.
- [KotlinAndroidApiGenerator](/docs/roundtrip-generator/api/kotlinandroidapigenerator/documentation/kotlinandroidapigenerator/) — Native Android clients using Retrofit and OkHttp.
- [KotlinSpringBootGenerator](/docs/roundtrip-generator/api/kotlinspringbootgenerator/documentation/kotlinspringbootgenerator/) — Spring Boot server projects.
- [TypeScriptApiGenerator](/docs/roundtrip-generator/api/typescriptapigenerator/documentation/typescriptapigenerator/) — TypeScript clients with optional TanStack Query helpers.
- [OpenApiYamlGenerator](/docs/roundtrip-generator/api/openapiyamlgenerator/documentation/openapiyamlgenerator/) — OpenAPI YAML.
- [GeneratorModels](/docs/roundtrip-generator/api/generatormodels/documentation/generatormodels/) — Shared API description types.
- [GeneratorBuilder](/docs/roundtrip-generator/api/generatorbuilder/documentation/generatorbuilder/) — Shared text-generation primitives.
